# Tech Stack

The tools and libraries used to build BroncoNotes.

Frontend:

- Next.js 14 (App Router)
- React 18
- TypeScript

Styling and UI:

- Tailwind CSS
- shadcn/ui
- Radix UI
- cmdk (search command)
- lucide-react (icons)
- next-themes (light and dark mode)
- Sonner (toast notifications)

Backend and Database:

- Convex (real-time database and backend functions)

Authentication:

- Clerk

State Management:

- Zustand
- usehooks-ts

Tooling:

- ESLint
- PostCSS
- Trunk

Project Structure:

- app: marketing landing page and the main app (sidebar, navbar, documents)
- components: shadcn/ui components, modals, and providers
- convex: schema, queries and mutations, auth config
- hooks: custom React hooks
- lib: shared utilities
- public: static assets

Personal project adapted from Fullstack Notion Clone by Antonio Erdeljac
